# Tank Battle HTML Game

A browser-based tank battle game inspired by classic top-down arcade tank games.

## Features

- Single-file HTML/CSS/JavaScript implementation
- Player tank movement and shooting
- Enemy tank AI with path changes and firing
- Destructible brick walls, solid steel walls, water, forest, and ice tiles
- Base defense objective
- Score, lives, level progression, pause, and restart controls
- Keyboard and touch controls

## Play

Open `index.html` in a browser.

Controls:

- `WASD` or arrow keys: move
- `Space`: fire
- `P`: pause
- `R`: restart

## Notes

No build step or dependencies are required.
